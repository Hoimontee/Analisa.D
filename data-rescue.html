Give valuable experimental datasets a life.

Beamtime is valuable — the resulting datasets can be even more valuable. We offer analysis or re-analysis of underused synchrotron, neutron and laboratory datasets — old, incomplete or never fully modelled — to extract new scientific value from them.

Typical situations

A synchrotron experiment was completed but only preliminary analysis was performed.
A neutron scattering dataset was collected but never fully modelled.
A PhD project ended before all measurements could be analysed.
A researcher has inherited datasets from a previous group member.
A publication used only part of a large experimental dataset.
New analysis methods now make an old dataset more informative.
A new scientific question has emerged from an existing dataset.
A facility measurement was technically successful but analysis was postponed.

Example scenarios

Typical rescue situations

Illustrative, anonymised scenarios — not client results.

Scenario A

Unfinished beamtime

Starting point: Variable-temperature synchrotron PXRD collected, only a few patterns refined.

What re-analysis can offer: A consistent refinement across the full series and a clear picture of the phase evolution.

Scenario B

Inherited neutron data

Starting point: Neutron total-scattering data left behind after a group member moved on.

What re-analysis can offer: Reprocessing, validation and a first real-space analysis that shows whether the data support a publication.

Scenario C

New question, old data

Starting point: A dataset analysed for average structure years ago; local disorder is now of interest.

What re-analysis can offer: PDF analysis and model comparison to test local-structure hypotheses on existing measurements.
